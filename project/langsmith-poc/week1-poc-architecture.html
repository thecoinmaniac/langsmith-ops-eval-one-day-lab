Week 1 LangSmith PoC Architecture

Operator-first eval workflow: local scripts + LangSmith datasets/experiments + OpenAI-compatible inference endpoint

Week 1 Workflow

  • • Seed or refresh golden dataset in LangSmith
  • • Run v1/v2 on train + holdout split
  • • Compare metrics, then apply promotion gate
  • • Monitor recent runs for health/error signal

Core Components

  • • Local Python scripts orchestrate the full eval loop
  • • pipeline.py calls ChatOpenAI against opencode base URL
  • • LangSmith stores datasets, traces, and experiment metadata
  • • Reports are persisted locally for deterministic review

Failure Modes Seen

  • • Invalid LANGSMITH_API_KEY ⇒ 401 Unauthorized
  • • Missing/empty split examples ⇒ run-time validation error
  • • Wrong base URL path can break provider requests
  • • Keep smoke tests local before paid API experiments
